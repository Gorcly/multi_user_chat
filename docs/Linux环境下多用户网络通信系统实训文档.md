# Linux 环境下多用户网络通信系统实训文档

## 第五步：设计通信协议

### 要完成的内容

1. 明确客户端和服务器之间的数据格式；
2. 定义消息类型；
3. 设计统一的数据包结构；
4. 解决 TCP 粘包和拆包问题；
5. 区分 TCP 消息和 UDP 消息使用场景。

### 推荐消息类型

```c
#define MSG_REGISTER     1
#define MSG_LOGIN        2
#define MSG_PRIVATE      3
#define MSG_GROUP        4
#define MSG_FILE         5
#define MSG_LOGOUT       6
#define MSG_HEARTBEAT    7
#define MSG_BROADCAST    8
#define MSG_ERROR        9
```

### 推荐数据包结构

```c
typedef struct Packet {
    int type;
    int length;
    char sender[32];
    char receiver[32];
    char data[1024];
} Packet;
```

### TCP 和 UDP 的使用划分

| 协议 | 使用场景 | 原因 |
|---|---|---|
| TCP | 登录、注册、私聊、文件传输 | 可靠、有序、不会丢包 |
| UDP | 广播消息、系统通知 | 速度快、适合简单广播 |

### TCP 粘包处理方式

TCP 是字节流协议，可能出现粘包或半包问题。因此需要在数据包中加入 `length` 字段。

处理思路：

1. 先读取固定长度的数据包头；
2. 根据数据包头中的 `length` 字段判断正文长度；
3. 再读取完整正文；
4. 保证每次处理的是一个完整数据包。

### 本阶段产出

- 完成通信协议设计；
- 明确每种消息类型的作用；
- 完成统一数据包结构设计；
- 为客户端和服务器通信提供统一标准。

```c

pthread_mutex_lock(&user_mutex);
```

### 需要加锁的位置

1. 添加用户；

3. 修改用户在线状态；

## 第十步：实现 TCP 私聊和群聊功能

### 要完成的内容

1. 客户端输入消息接收者；
2. 客户端发送私聊消息包；
3. 服务器根据用户名查找目标用户；
4. 如果目标用户在线，则转发消息；
5. 如果目标用户不在线，则返回错误信息；
6. 群聊消息由服务器转发给所有在线用户。

### 私聊流程

```text
用户 A 输入目标用户 B 和消息内容
    ↓
客户端 A 发送消息到服务器
    ↓
服务器查找用户 B
    ↓
用户 B 在线则转发消息
    ↓
用户 B 客户端显示消息
```

### 群聊流程

```text
用户发送群聊消息
    ↓
服务器遍历在线用户链表
    ↓
向所有在线用户转发消息
```

### 本阶段产出

- 在线用户之间可以私聊；
- 在线用户之间可以群聊；
- 服务器能够完成消息转发；

2. 在线通知；

3. 重要消息不要使用 UDP；
4. 注册、登录、文件传输必须使用 TCP。

### 常见异常处理方式

| 异常情况 | 处理方式 |
|---|---|
| 客户端断开连接 | 关闭 socket，移除在线用户 |

| 密码错误 | 返回登录失败 |
| 目标用户不在线 | 返回错误提示 |
| 文件不存在 | 客户端提示重新选择 |
| send 失败 | 关闭连接并清理资源 |
| recv 返回 0 | 判断客户端已断开 |
| malloc 失败 | 输出错误并返回 |

### 本阶段产出

- 系统具备基本异常处理能力；
- 客户端断开不会导致服务器崩溃；
- 用户操作错误时有明确提示；

## 第十四步：编写 Makefile 完成项目构建

### 要完成的内容

1. 将服务器、客户端、公共模块分开编译；
2. 使用 Makefile 管理编译过程；
3. 支持一键编译；
4. 支持清理编译产物；
5. 编译时打开警告和调试信息。

### 示例 Makefile

```makefile
CC = gcc
CFLAGS = -Wall -g -Iinclude -pthread

SERVER_SRC = server/server.c common/protocol.c common/user.c
CLIENT_SRC = client/client.c common/protocol.c

SERVER_TARGET = server_app
CLIENT_TARGET = client_app

all: $(SERVER_TARGET) $(CLIENT_TARGET)

$(SERVER_TARGET): $(SERVER_SRC)
	$(CC) $(CFLAGS) $^ -o $@

$(CLIENT_TARGET): $(CLIENT_SRC)
	$(CC) $(CFLAGS) $^ -o $@

clean:
	rm -f $(SERVER_TARGET) $(CLIENT_TARGET)
```

编译命令：

```bash
make
```

清理命令：

```bash
make clean
```

### 本阶段产出

- 项目支持 Makefile 一键构建；
- 服务器端和客户端可以分别生成可执行文件；
- 项目结构更加规范。

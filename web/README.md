# WSL Web 客户端

该目录提供多用户聊天系统的 Web 访问入口。Web 层负责浏览器界面和协议网关，C 服务端仍单独运行。

## 端口

| 端口 | 用途 |
|---|---|
| `8080` | 客户端聊天界面 |
| `8081` | 服务端界面占位页 |
| `9000` | C 服务端 TCP：注册、登录、聊天、文件 |
| `9001` | C 服务端 UDP：广播 |

Web 端口可通过环境变量覆盖：

```bash
CLIENT_WEB_PORT=8080 SERVER_WEB_PORT=8081 npm run dev
```

## 启动

终端 1 启动 C 服务端：

```bash
cd ~/multi_user_chat
make
./server_app 9000 9001
```

终端 2 启动 Web 网关：

```bash
cd ~/multi_user_chat/web
npm install
npm run dev
```

Windows 浏览器访问：

```text
http://localhost:8080
```

服务端界面占位页：

```text
http://localhost:8081
```

## 当前界面

客户端界面已经按聊天软件样式重新整理：

- 左侧为联系人侧栏，支持“好友列表 / 群组列表”切换；
- 好友列表显示在线、离线状态，在线用户由 C 服务端实时返回；
- 群组列表与好友列表使用同一套列表样式，不再使用弹窗式群组面板；
- 右侧为聊天窗口，包含聊天对象状态、聊天记录和底部输入区；
- 顶部不显示电话、视频按钮，仅保留信息和更多操作入口；
- 底部只保留一个“发送”按钮；选择文件后，文件会以附件卡片形式显示在输入框上方，再点击“发送”即可发送文件；
- 支持私聊、群聊、文件发送、文件接收下载、UDP 广播提示、退出登录。

## 使用说明

1. 登录或注册后进入聊天界面；
2. 在左侧选择好友后，输入文字并点击“发送”进行私聊；
3. 在左侧切换到“群组列表”，选择群组后，输入文字并点击“发送”进行群聊；
4. 点击输入框左侧附件按钮选择文件；
5. 选择文件后，确认当前会话对象为好友，再点击“发送”发送文件；
6. 文件发送不再使用单独的“发送文件”按钮。
